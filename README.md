# BTC シグナルモニター(PWA)

BTC/USDT の1時間足を常時監視し、以下のシグナル候補を検知してブラウザ通知するPWAです。

## 監視ロジック(すべて確定足で判定・リペイントなし)

| シグナル | 条件 | 種別 |
|---|---|---|
| ゴールデンクロス | SMA50 が SMA200 を上抜け | 買い |
| デッドクロス | SMA50 が SMA200 を下抜け | 売り |
| BB下限反発 | 終値が -2σ を割った後、バンド内に復帰 | 買い候補(上昇トレンド中は強め) |
| BB上限反落 | 終値が +2σ を超えた後、バンド内に反落 | 売り・利確候補(下降トレンド中は強め) |

- データ: Binance 公開API(無料・APIキー不要)。60秒ごとに自動更新
- BB設定: 期間20、±2σ
- シグナル履歴は localStorage に保存(最大100件)

## ローカルで起動

```bash
cd btc-signal-pwa && python3 -m http.server 8321
```

→ http://localhost:8321 を開く

## スマホでも使うには(GitHub Pages 推奨・無料)

PWAのインストールとService WorkerにはHTTPSが必要です。

1. GitHubに新規リポジトリを作成し、このフォルダの中身をpush
2. リポジトリの Settings → Pages → Branch: main / root を選択
3. 発行されたURL(https://ユーザー名.github.io/リポジトリ名/)をスマホで開く
4. **iPhone**: Safari → 共有 →「ホーム画面に追加」 / **Android**: Chrome → メニュー → 「アプリをインストール」
5. アプリを開いて「🔔 通知を有効にする」をタップ

## 通知に関する制限(重要)

- **デスクトップ**: タブまたはインストールしたPWAを開いたままにしておけば、シグナル発生時(足確定時)に通知されます
- **スマホ**: 画面を開いている間は通知されます。**アプリを完全に閉じている間のバックグラウンド通知には、プッシュ配信サーバーが別途必要**です(無料APIのみのサーバーレス構成では不可)。常時監視したい場合はデスクトップで開きっぱなしにするのが確実です
